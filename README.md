# Simulation Project

## Overview
This project implements a numerical simulation framework with modules for:
- Particle positions and velocities
- Force computation
- Energy calculation
- Observables tracking
- Data analysis and visualization

## Project Structure
- `main.py` – Entry point of the simulation
- `simulation.py` – Core simulation loop
- `forces.py` – Force calculations
- `energies.py` – Energy computations
- `energies_plot.py` – Plotting energy results
- `observables.py` – Measurable quantities
- `pos_and_vel.py` – Initialization of positions and velocities
- `data_analysis.py` – Post-processing tools
- `animation.py` – Visualization of simulation

## Requirements
- Python 3.x
- numpy
- matplotlib

## Usage
Run the simulation with:
```bash
python main.py
```

## Output
The simulation generates:
- Energy plots
- Optional animations
- Data files for further analysis

## Notes
Customize parameters directly in the source files or main script depending on your needs.
